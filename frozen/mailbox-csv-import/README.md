# Архив: CSV-импорт пула почтовых ящиков

**Статус:** архивирован 2026-08-14. Функция недоступна в рабочем интерфейсе.

Импорт временно убран, потому что подключение Яндекс 360 перешло на единый
пароль приложения для SMTP и IMAP, а массовый формат и сценарий ошибок нужно
перепроектировать под эту модель.

Сохранено:

- `csv.ts` — прежний парсер колонок email, имени, SMTP- и IMAP-паролей;
- `action.ts.txt` — прежний server action массового подключения;
- `MailboxCsvImport.tsx.txt` — прежний блок формы.

Чтобы вернуть функцию, сначала замените две парольные колонки одной колонкой
`Пароль приложения`, затем верните парсер в `src/lib/mail`, server action — в
`src/app/(app)/app/mailboxes/actions.ts`, а блок формы — в экран инфраструктуры.
