# Замороженная фича: HTML-шаблоны писем

**Статус:** архивировано 2026-08-04. Эти файлы не импортируются рабочим
приложением и исключены из компиляции через `tsconfig.json` → `exclude:
["frozen"]`.

В архив перенесены: галерея и пользовательские HTML-шаблоны, редактор
фирменного оформления, предпросмотр письма, API предпросмотра и генерация
картинок через fal.ai. Данные в БД намеренно не удалялись.

Рабочая рассылка теперь создаёт только текстовые письма. Для включённого Open
Rate `src/server/sendEngine.ts` формирует минимальную HTML-альтернативу с
пикселем открытия; ссылок для отслеживания кликов она не создаёт.

Чтобы вернуть архив, переносите нужные модули обратно в `src/`, восстановите
импорты и UI мастера кампаний, затем отдельно проверьте безопасность HTML и
оплату внешнего API изображений.
