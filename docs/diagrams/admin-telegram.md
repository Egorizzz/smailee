# Закрытый Telegram-бот администратора

Отдельный служебный бот не связан с клиентским Telegram-ботом и не получает
клиентские лиды из рассылок. Он принимает только заявки самого Smailee: форму
на сайте и запрос «Помочь с инфраструктурой».

Доступ выдаёт пользователь с ролью `ADMIN` одноразовой ссылкой на 15 минут.
Получателей может быть несколько; каждого можно отозвать в админке. Сначала
заявка сохраняется в основной таблице, затем для всех активных получателей
создаются записи очереди. Поэтому сбой Telegram не теряет заявку и не ломает
ответ формы: worker повторяет доставку с увеличивающейся задержкой.

```mermaid
flowchart TD
  Admin([Администратор Smailee]) --> Token{TELEGRAM_ADMIN_BOT_TOKEN задан?}
  Token -->|нет| Configure[Создать отдельного бота в BotFather<br/>и добавить токен в окружение]
  Configure --> Restart[Перезапустить web и worker]
  Restart --> Access
  Token -->|да| Access[В админке нажать «Выдать доступ»]
  Access --> Link[Одноразовая ссылка<br/>15 минут, одно использование]
  Link --> Start[Получатель открывает личный чат<br/>и нажимает Start]
  Start --> Check{Ссылка действительна<br/>и выдана ADMIN?}
  Check -->|нет| Denied([Доступ не создаётся])
  Check -->|да| Recipient[Чат добавлен в список получателей]

  Site([Форма на сайте]) --> SaveLead[Сохранить LandingLead]
  Setup([Запрос помощи<br/>с инфраструктурой]) --> SaveSetup[Сохранить SetupRequest]
  SaveLead --> Queue[Создать доставку для каждого<br/>активного получателя]
  SaveSetup --> Queue
  Queue --> Worker[Worker забирает очередь]
  Worker --> Send{Telegram принял сообщение?}
  Send -->|да| Delivered([Заявка в личном чате<br/>с кнопкой в админку])
  Send -->|временный сбой| Retry[Повторить с backoff]
  Retry --> Worker
  Send -->|бот заблокирован<br/>или чат удалён| Revoke[Отозвать получателя<br/>и остановить его очередь]
  Recipient --> Manage{Доступ оставляем?}
  Manage -->|нет| Revoke
  Manage -->|да| Queue
```

**Когда обновлять.** При добавлении нового типа системного уведомления,
изменении правил доступа, источника заявок, очереди или политики повторов.
