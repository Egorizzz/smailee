# Inbox: состояния коммуникации и автопинг

Inbox группирует письма по паре «кампания + контакт». Исходное письмо,
follow-up и ответы не создают отдельные строки. По умолчанию коммуникации
сортируются по последнему реальному событию, а обработанные скрыты.

## Как организация настраивает стиль ИИ

```mermaid
flowchart LR
  File[Файл TXT, CSV или MD] --> Analyze[Анализ примеров диалогов]
  Analyze --> Style[Ориентиры по тону и сценарию]
  Manual[Дополнительные комментарии] --> Compose[Единая инструкция ответа]
  Style --> Compose
  Compose --> Reply[Черновик или автоответ ИИ]
```

Файл с примерами и дополнительные комментарии можно использовать по отдельности
или одновременно. Ориентиры из диалогов и комментарии сохраняются раздельно;
при конфликте ручные комментарии имеют приоритет.

## Жизненный цикл диалога

```mermaid
flowchart TD
  Sent([Отправлено исходное письмо]) --> Reply{Клиент ответил?}
  Reply -->|нет| Followups[Показать будущие follow-up<br/>ручное письмо недоступно]
  Reply -->|да| Classify[ИИ обновляет квалификацию<br/>и резюме]
  Classify --> Decline{Распознан отказ?}
  Decline -->|явное «не пишите»| Refused[Стоп-лист и папка «Отказы»]
  Decline -->|коммерческий отказ| Confirm[Предложить оператору<br/>подтвердить отказ]
  Decline -->|нет| AiMode{Ответы ИИ включены<br/>в этом диалоге?}
  AiMode -->|да| Draft[Черновик ИИ или автоответ]
  AiMode -->|нет| Manual[Ручной режим<br/>квалификация остаётся]
  Draft --> Outbound[Отправлен наш ответ]
  Manual --> Outbound
  Outbound --> Wait{Новый ответ клиента?}
  Wait -->|да| Classify
  Wait -->|нет, меньше 7 дней| Quiet[Ожидание]
  Wait -->|нет, 7+ дней| Frost[Папка «Мороз»]
  Frost --> Ping{Автопинг включён?}
  Ping -->|нет| Operator[Предложить настройку<br/>в Аналитике и Inbox]
  Ping -->|да| Window{Будни, 09:00–19:00 МСК?}
  Window -->|нет| Window
  Window -->|да| AutoPing[ИИ отправляет короткий пинг]
  AutoPing --> Limit{Достигнут максимум<br/>попыток пользователя?}
  Limit -->|нет| Wait
  Limit -->|да| Stop[Автопинг остановлен]
```

Если клиент назвал дату следующего контакта, «Мороз» и автопинг откладываются
до неё. Черновик не считается ответом: индикатор действия снимается только
после реально отправленного исходящего письма, обработки, отказа или передачи.
