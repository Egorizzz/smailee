# База контактов: от файла до готовых получателей

Начало — файл с базой, конец — **контакты в системе, размеченные и готовые к
кампании**. Отдельный процесс, а не часть рассылки: базу загружают один раз и
используют во многих кампаниях.

Сюда же входит стоп-лист, но только как **фильтр на входе** — сам он
наполняется в процессе рассылки (см. `campaign.md`, ветка отказа).

**Когда обновлять.** Если меняется путь загрузки: форматы, шаги подтверждения
разметки, правила отбраковки строк.

**Как править.** Карандаш в интерфейсе GitHub (вкладка Preview покажет
результат) либо `npm run diagram:link docs/diagrams/contacts.md`.

```mermaid
flowchart TD
  Start([Есть база контактов]) --> Upload[Загрузить файл<br/>CSV, TSV или XLSX]
  Upload --> Read{Файл читается?}
  Read -->|не тот формат| ErrFormat[Поддерживаются CSV, TSV, XLSX]
  Read -->|слишком большой| ErrSize[Разбить базу на части]
  Read -->|пусто или не таблица| ErrEmpty[Файл не похож на таблицу]
  ErrFormat --> Upload
  ErrSize --> Upload
  ErrEmpty --> Upload

  Read -->|слишком много текста или полей| ErrComplex[Упростить структуру файла]
  ErrComplex --> Upload
  Read -->|да, один лист| Guess[Разметка колонок:<br/>сначала локальной эвристикой]
  Read -->|да, несколько листов| Multi[Определить роли листов:<br/>контакты, проверка email, справка]
  Multi --> Match[Связать строки:<br/>точный email; затем только уникальные<br/>ИНН, домен или телефон]
  Match --> Preview
  Guess --> Unknown{Остались непонятные колонки<br/>или не найден email?}
  Unknown -->|да| MapAi{DeepSeek доступен?}
  MapAi -->|да| AiMap[ИИ предлагает разметку<br/>только для непонятных колонок]
  MapAi -->|нет| LocalMap[Остаётся результат эвристики<br/>ничего фиктивного не подставляется]
  Unknown -->|нет| Preview
  AiMap --> Preview
  LocalMap --> Preview
  Preview[Показываем разметку и примеры строк<br/>ДО сохранения]
  Preview --> Confirm{Разметка верна?}
  Confirm -->|нет| Fix[Поправить соответствие колонок вручную]
  Fix --> Preview

  Confirm -->|да| HasEmail{Колонка с email найдена?}
  HasEmail -->|нет| NoEmail[Импортировать нечего —<br/>без адреса контакт бесполезен]
  NoEmail --> Fix

  HasEmail -->|да| Clean[Нормализация: несколько email в ячейке,<br/>дубли объединяются без потери полей;<br/>неоднозначные строки сохраняются отдельно]
  Clean --> Segment{В файле есть колонка сегмента?}
  Segment -->|да| Quota
  Segment -->|нет| AskAi{Разметить сегменты автоматически?}
  AskAi -->|да| SegAvailable{DeepSeek доступен?}
  SegAvailable -->|да| AiSeg[ИИ размечает по названиям компаний]
  SegAvailable -->|нет| NoAiSeg[Импорт продолжается без автосегментов]
  AskAi -->|нет| Quota
  AiSeg --> Quota
  NoAiSeg --> Quota

  Quota{Доступ активен и хватает квоты<br/>на новые уникальные email?}
  Quota -->|нет| Deny[Отказ и подсказка<br/>про оплату или тариф выше]
  Deny --> Plan[Оплатить или поднять тариф<br/>см. billing.md]
  Plan --> Quota
  Quota -->|да| Queue[Транзакция: резерв квоты<br/>и очередь уникальных email]
  Queue --> Assess[Worker: пакетная LLM-оценка,<br/>хватает ли данных строки для персонализации]
  Assess --> Import[Возобновляемый импорт пакетами]

  Import --> Check{Проверка каждого контакта}
  Check -->|email в стоп-листе| Blocked[Сохранён, но помечен отписанным<br/>письма не получит]
  Check -->|адрес уже в базе| Update[Обновляем данные,<br/>дубля не создаём]
  Check -->|есть приложенный отчёт| External[Использовать результат из книги;<br/>Reoon не вызывать]
  Check -->|отчёта нет| Verify[Проверить через Reoon с кэшем]
  External --> Enrich
  Verify --> Enrich
  Enrich{Контекст достаточен<br/>с высокой уверенностью?}
  Enrich -->|да| Fresh[Активный контакт;<br/>анализ сайта пропущен]
  Enrich -->|нет или LLM недоступен| Site[Анализ уникального сайта<br/>до двух страниц, с кэшем]
  Site --> Fresh

  Blocked --> Done
  Update --> Done
  Fresh --> Done([База готова — можно создавать кампанию])
```
