# База контактов: от файла до готовых получателей

Начало — файл с базой, конец — **контакты в системе, размеченные и готовые к
кампании**. Отдельный процесс, а не часть рассылки: базу загружают один раз и
используют во многих кампаниях.

Сюда же входит стоп-лист, но только как **фильтр на входе** — сам он
наполняется в процессе рассылки (см. `campaign.md`, ветка отказа).

**Когда обновлять.** Если меняется путь загрузки: форматы, шаги подтверждения
разметки, правила отбраковки строк.

**Как править.** Карандаш в интерфейсе GitHub (вкладка Preview покажет
результат) либо `npm run diagram:link docs/diagrams/contacts.md`.

```mermaid
flowchart TD
  Start([Есть база контактов]) --> Upload[Загрузить файл<br/>CSV, TSV или XLSX]
  Upload --> Read{Файл читается?}
  Read -->|не тот формат| ErrFormat[Поддерживаются CSV, TSV, XLSX]
  Read -->|больше 10 МБ| ErrSize[Разбить базу на части]
  Read -->|пусто или не таблица| ErrEmpty[Файл не похож на таблицу]
  ErrFormat --> Upload
  ErrSize --> Upload
  ErrEmpty --> Upload

  Read -->|да| Guess[Разметка колонок:<br/>сначала по названиям,<br/>непонятные отдаём ИИ]
  Guess --> Preview[Показываем разметку и примеры строк<br/>ДО сохранения]
  Preview --> Confirm{Разметка верна?}
  Confirm -->|нет| Fix[Поправить соответствие колонок вручную]
  Fix --> Preview

  Confirm -->|да| HasEmail{Колонка с email найдена?}
  HasEmail -->|нет| NoEmail[Импортировать нечего —<br/>без адреса контакт бесполезен]
  NoEmail --> Fix

  HasEmail -->|да| Clean[Отбраковка: строки без валидного email<br/>и дубли внутри файла отбрасываются]
  Clean --> Segment{В файле есть колонка сегмента?}
  Segment -->|да| Quota
  Segment -->|нет| AskAi{Разметить сегменты автоматически?}
  AskAi -->|да| AiSeg[ИИ размечает по названиям компаний]
  AskAi -->|нет| Quota
  AiSeg --> Quota

  Quota{Доступ активен и хватает<br/>лимита контактов на тарифе?}
  Quota -->|нет| Deny[Отказ с указанием лимита<br/>и подсказкой про тариф]
  Deny --> Plan[Оплатить или поднять тариф<br/>см. billing.md]
  Plan --> Quota
  Quota -->|да| Import[Импорт построчно]

  Import --> Check{Проверка каждого контакта}
  Check -->|email в стоп-листе| Blocked[Сохранён, но помечен отписанным<br/>письма не получит]
  Check -->|адрес уже в базе| Update[Обновляем данные,<br/>дубля не создаём]
  Check -->|новый и чистый| Fresh[Активный контакт]

  Blocked --> Done
  Update --> Done
  Fresh --> Done([База готова — можно создавать кампанию])
```
