# Кабинет организации: приглашения, доступы и пароль

Кабинет принадлежит организации, а не отдельному сотруднику. Администратор добавляет коллег по email, выбирает стартовый набор доступов и при необходимости включает каждый доступ отдельно. Ссылки на установку и восстановление пароля одноразовые, в базе хранится только хеш токена.

```mermaid
flowchart TD
  Admin([Администратор организации]) --> Team[Настройки → Команда]
  Team --> Email[Указывает email сотрудника]
  Email --> Rights[Выбирает шаблон или отдельные доступы]
  Rights --> Invite[Создаётся сотрудник и одноразовая ссылка]
  Invite --> Mail{Системный SMTP настроен?}
  Mail -->|да| Received[Сотрудник получает письмо]
  Mail -->|нет| Saved[Сотрудник добавлен, админ настраивает SMTP и отправляет ссылку повторно]
  Saved --> Invite
  Received --> SetPassword[Сотрудник вводит пароль и подтверждение<br/>может показать пароль]
  SetPassword --> Token{Ссылка валидна<br/>и не использована?}
  Token -->|нет| NewLink[Запросить новую ссылку]
  NewLink --> Invite
  Token -->|да| Login[Вход в кабинет организации]

  Login --> Check{Какие доступы включены?}
  Check --> Default[Сразу открывается первый доступный раздел<br/>или экран «Нет назначенных доступов»]
  Check --> Contacts[База контактов: просмотр / управление]
  Check --> Campaigns[Кампании: свои или все;<br/>контакты получателей — отдельный доступ]
  Check --> Stats[Статистика: свои или общая]
  Check --> Leads[Лиды: свои кампании или все]
  Check --> Infra[Инфраструктура и тариф]
  Check --> Settings[Настройки организации]
  Infra --> AdminOnly{Администратор?}
  Settings --> AdminOnly
  AdminOnly -->|да| Manage[Управляет настройками и командой]
  AdminOnly -->|нет| Denied([Раздел недоступен])

  Login --> Forgot[«Забыли пароль»]
  Forgot --> ResetEmail[Ссылка восстановления на email]
  ResetEmail --> SetPassword

  Check --> AI[Генерация/автоответ ИИ]
  AI --> API{Общий AI API доступен?}
  API -->|да| Generated[Генерация или черновик ответа]
  API -->|нет| AIError[Показать «ИИ сейчас недоступен»<br/>ничего не подставлять и не отправлять]
  AIError --> Incident[Баннер в ЛК администратора<br/>+ письмо с no-reply на ADMIN_EMAIL]
```

Доступы проверяются на сервере для каждого действия, а не только скрывают кнопки. Если для страницы доступна лишь часть действий, недоступные элементы остаются серыми и объясняют причину при нажатии. Право «Контакты получателей кампании» дополнительно защищает имя, компанию, email и персональный предпросмотр письма. Сотрудник работает с общими данными организации; автор кампании фиксируется отдельно, чтобы ограничение «только свои кампании/лиды» было проверяемым.

Недоступность общего API фиксируется как инцидент: баннер видит только администратор организации, а письмо отправляется не чаще раза в 15 минут для каждого сервиса. При следующем успешном запросе инцидент закрывается автоматически.
