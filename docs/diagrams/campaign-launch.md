# Запуск кампании

Путь от «создать кампанию» в мастере до отправленного письма. Укрупнённо: только
то, что видит и проходит пользователь, плюс решения движка, которые меняют исход.

**Когда обновлять.** Если изменение добавляет, убирает или переставляет шаг, через
который проходит пользователь, либо меняет условие ветвления — диаграмма
устарела. Внутренние правки (как именно устроен захват партии, как
классифицируется ошибка) сюда не попадают намеренно.

**Как править.** Прямо здесь: карандаш в интерфейсе GitHub, вкладка Preview
показывает результат, коммит уходит в репозиторий. Либо в живом редакторе с
мгновенным превью — `npm run diagram:link docs/diagrams/campaign-launch.md`,
и потом вернуть правку обратно: `npm run diagram:pull <файл> "<ссылка>"`.

```mermaid
flowchart TD
  Start([Пользователь: создать кампанию]) --> S1[Шаг 1 — Кому<br/>название, выбор сегментов]
  S1 --> S2[Шаг 2 — Письмо]
  S2 --> Multi{Сегментов больше одного?}
  Multi -->|да| Tabs[ИИ пишет свой текст под каждый сегмент<br/>вкладки: переключаешь и правишь]
  Multi -->|нет| One[ИИ пишет варианты<br/>выбираешь один]
  Tabs --> S3
  One --> S3
  S3[Шаг 3 — Запуск<br/>follow-up, трекинг открытий, отложенный старт]

  S3 --> Create[Создание кампании]
  Create --> Norm[Плейсхолдеры к виду name и company]
  Norm --> Quota{Хватает месячной квоты тарифа?}
  Quota -->|нет| Deny[Отказ с указанием лимита]
  Quota -->|да| Fanout[На каждый сегмент — отдельная кампания<br/>письма материализуются в PENDING]

  Fanout --> Launch[Запуск]
  Launch --> Warm{Есть прогретый ящик?}
  Warm -->|нет| Await[Кампания ждёт<br/>воркер стартует сам, когда ящик станет warm]
  Warm -->|да| Queue[В очередь]
  Await -.->|ящик прогрелся| Queue

  Queue --> Window{Внутри окна отправки?<br/>Пн–Пт, 9–19 МСК}
  Window -->|нет| Hold[Ждём открытия окна]
  Hold -.-> Window
  Window -->|да| Claim[Захват партии писем<br/>защита от двойной отправки]

  Claim --> Pool[Пул ящиков: прогретые и рабочие]
  Pool --> Rotate[Ротация по доменам и ящикам<br/>за перепиской закреплён свой ящик]
  Rotate --> Limits{Лимиты: 30 на ящик, 120 на домен}
  Limits -->|исчерпаны| Requeue[Остаток обратно в очередь<br/>добьём в следующее окно]
  Limits -->|есть слот| Send[Отправка через SMTP ящика]

  Send --> Ok{Успех?}
  Ok -->|да| Sent[Письмо отправлено]
  Ok -->|отказ логина| Broken[Письмо провалено<br/>ящик помечен и выведен из ротации]

  Sent --> Empty{Очередь пуста?}
  Empty -->|нет| Window
  Empty -->|да| Done([Кампания завершена])
  Requeue -.->|следующий день| Window
```
