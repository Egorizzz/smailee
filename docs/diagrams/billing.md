# Тариф: от упёртого лимита до поднятых квот

Начало — упёрлись в ограничение, конец — **лимиты подняты и работа
продолжается** (либо осознанно остались на текущем тарифе). Процесс идёт
фоном через всю работу: сам по себе тариф не нужен, о нём вспоминают в момент
отказа.

Тариф всегда возвращается к «Демо» по истечении срока — отдельного действия
для этого не требуется, поэтому цикл замкнут.

**Когда обновлять.** Если меняются точки, где пользователь упирается в лимит,
или путь оплаты и продления.

**Как править.** Карандаш в интерфейсе GitHub (вкладка Preview покажет
результат) либо `npm run diagram:link docs/diagrams/billing.md`.

```mermaid
flowchart TD
  Start([Упёрлись в ограничение]) --> Where{Где именно}
  Where -->|загружаю базу| LimitContacts[Лимит числа контактов]
  Where -->|создаю кампанию| LimitEmails[Лимит писем в месяц]

  LimitContacts --> Open[Раздел «Тариф»]
  LimitEmails --> Open
  Open --> Choose{Что делаем}

  Choose -->|остаёмся как есть| Reduce([Работаем в текущих лимитах:<br/>меньше контактов или дождаться месяца])
  Choose -->|включаю демо впервые| Demo{Бесплатный план и демо ещё не использовано?}
  Demo -->|да| DemoActive[Демо-доступ: лимиты START<br/>на 14 дней, до 2 000 контактов]
  Demo -->|нет| Pay[Оплата через платёжный шлюз]
  Choose -->|берём тариф выше| Pay
  Choose -->|это пилот| Admin[Администратор включает тариф вручную<br/>без оплаты]

  Pay --> Confirm{Платёж подтверждён?}
  Confirm -->|шлюз ещё не ответил| Pending[Платёж ожидает,<br/>тариф пока прежний]
  Pending -.->|подтверждение пришло| Confirm
  Confirm -->|да| Active

  Admin --> Active[Тариф активен 30 дней,<br/>лимиты подняты]
  DemoActive --> Work
  Active --> Work([Работа продолжается])

  Work --> Renew{Срок подходит к концу}
  Renew -->|продлеваю| Pay
  Renew -->|не продлеваю| Expire[Срок истёк]
  Expire --> Fallback[Автоматический откат<br/>на лимиты «Демо»]
  Fallback --> Start
```
