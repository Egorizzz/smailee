# Юридические документы, согласия и cookies

Каждый человек, работающий в кабинете, явно принимает актуальную редакцию
Пользовательского соглашения. Принятие фиксируется датой и версией документа.
Публичная оферта относится не к входу сотрудника, а к приобретению доступа
организацией: её акцептует уполномоченный плательщик оплатой выбранного тарифа,
а версия оферты сохраняется в конкретном платеже.

Заявка на демонстрацию использует отдельное согласие на обработку персональных
данных: без флажка API отклоняет форму, а у принятой заявки сохраняются дата и
версия согласия. Необходимые cookies работают для входа и хранения выбора.
Аналитика по умолчанию выключена и не загружается до явного разрешения.

Существенная новая редакция Пользовательского соглашения меняет системную
версию. При следующем входе старый акцепт больше не пропускает в кабинет:
пользователь читает новую редакцию и подтверждает её отдельно. Создание заявки
на платёж не проставляет согласие автоматически.

```mermaid
flowchart TD
  Login([Пользователь входит в Smailee<br/>по одноразовой ссылке или с паролем]) --> Agreement{Принята текущая версия<br/>Пользовательского соглашения?}
  Agreement -->|нет| Accept[Чекбокс и явное подтверждение<br/>фиксируются дата + версия]
  Agreement -->|да| Cabinet[Кабинет организации]
  Accept --> Cabinet

  Cabinet --> Billing{Есть право<br/>«Тариф и оплата»?}
  Billing -->|нет| Work([Работа в пределах прав])
  Billing -->|да| Choose[Выбрать тариф]
  Choose --> Read[Ссылка на актуальную<br/>Публичную оферту]
  Read --> Renewal{Включить<br/>автопродление?}
  Renewal -->|снять выбранный флажок| Request[Создать разовый платёж<br/>со статусом PENDING]
  Renewal -->|оставить выбранным| Consent[Сохранить дату согласия,<br/>тариф, сумму и версию оферты]
  Consent --> Request
  Request --> Payment{Средства фактически<br/>получены и подтверждены?}
  Payment -->|нет| Pending[Договор ещё не заключён<br/>доступ не продлевается]
  Pending --> Payment
  Payment -->|да| Offer[Оферта акцептована оплатой<br/>версия хранится в Payment]
  Offer --> Active([Оплаченный доступ активирован])
  Active --> Cancel{Автопродление включено<br/>и пользователь отключает его?}
  Cancel -->|да| Stop[Остановить будущие списания<br/>сохранить оплаченный срок]
  Cancel -->|нет| Active

  NewTerms([Опубликована существенная<br/>новая редакция соглашения]) --> Version[Изменена системная версия]
  Version --> Login
```

```mermaid
flowchart TD
  Visit([Посетитель открывает сайт]) --> CookieChoice{Есть выбор cookies<br/>текущей версии?}
  CookieChoice -->|да| Apply[Применить сохранённые категории]
  CookieChoice -->|нет| Banner[Показать компактный баннер]
  Banner --> All[Принять все]
  Banner --> Necessary[Только необходимые]
  Banner --> Settings[Настроить категории]
  Settings --> Save[Сохранить выбор]
  All --> Analytics[Разрешить аналитику]
  Necessary --> Block[Не загружать аналитику]
  Save --> AnalyticsGate{Аналитика разрешена?}
  AnalyticsGate -->|да| Analytics
  AnalyticsGate -->|нет| Block
  Apply --> AnalyticsGate
  Analytics --> Site([Продолжить работу с сайтом])
  Block --> Site

  Site --> Demo[Открыть форму демо]
  Demo --> Consent{Отдельное согласие<br/>отмечено?}
  Consent -->|нет| Reject[Не отправлять заявку<br/>показать требование]
  Reject --> Demo
  Consent -->|да| Api[API повторно проверяет согласие]
  Api --> Store[Сохранить заявку + дату<br/>и версию согласия]
  Store --> Contact([Связаться по заявке])

  Site --> Reopen[Настройки cookies в подвале]
  Reopen --> Settings
```

**Когда обновлять.** Если меняется способ регистрации, акцепта, версия
документов, состав форм, момент заключения договора, платёжный путь, категории
cookies, аналитические поставщики или круг лиц, которые могут оплачивать тариф.
