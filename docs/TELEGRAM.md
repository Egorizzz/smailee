# Telegram-уведомления о лидах

## Что уже реализовано

- один общий бот обслуживает все клиентские организации;
- безопасная привязка личного чата через одноразовый deep-link на 15 минут;
- webhook защищён заголовком `X-Telegram-Bot-Api-Secret-Token`;
- username бота определяется автоматически через `getMe`;
- webhook и команды бота регистрируются автоматически при первом подключении;
- в уведомлении приходят контакт, резюме лида и кнопка перехода в Smailee;
- `/status` проверяет связь, `/stop` отключает уведомления, `/help` показывает справку;
- блокировка бота пользователем автоматически очищает нерабочую привязку;
- сбой Telegram не останавливает обработку письма или передачу лида в CRM.

## Что нужно сделать вручную

1. Открыть `@BotFather`, выполнить `/newbot`, задать имя и username.
2. Скопировать выданный токен в секрет окружения:

   ```env
   TELEGRAM_BOT_TOKEN=123456789:AA...
   ```

3. Убедиться, что `APP_URL` содержит публичный HTTPS-адрес приложения, и
   перезапустить приложение.

На этом настройка владельца продукта закончена. Пользователь открывает
`Интеграции → Telegram`, нажимает «Подключить Telegram» и затем `Start` в боте.
Приложение само вызовет `getMe`, `setWebhook` и `setMyCommands`.

## Поток привязки

1. Авторизованный администратор организации запрашивает подключение.
2. Smailee создаёт случайный токен, хранит только SHA-256 hash и срок действия.
3. Пользователь открывает `https://t.me/<bot>?start=<token>`.
4. Telegram присылает `/start <token>` на защищённый webhook Smailee.
5. Токен атомарно помечается использованным, а `chat.id` связывается с владельцем
   организации. Повторно использовать ссылку нельзя.

Бот принимает привязку только из личных чатов. Один Telegram-чат может быть
привязан только к одной организации; новая осознанная привязка заменяет старую.

## Переменные

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | секретный токен Bot API |
| `APP_URL` | база HTTPS URL для webhook и кнопки «Открыть лид» |

Отдельный webhook secret задавать не нужно: приложение детерминированно получает
его из токена бота и проверяет через constant-time comparison.
